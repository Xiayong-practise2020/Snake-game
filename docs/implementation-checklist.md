- [x] TypeScript + Vite + Canvas 2D，30×30 网格，200 ms 固定周期。
- [x] 开始、暂停、继续、结束、胜利和重开，实时分数与最终分数。
- [x] 方向键和 WASD；每周期最多一次有效转向；反向输入不占机会。

- [x] 控制键防滚动；长按空格不重复切换；按钮焦点下空格无双重触发。
- [x] Canvas 使用 900×900 逻辑像素，根据 devicePixelRatio 绘制；HTML 展示分数与状态。
- [x] `npm run typecheck` 通过。
- [x] `npm run test`：12 项单元测试全部通过（含 2 项 Windows 启动服务测试）。

- [x] 页面截图人工检查；开始界面与操作提示显示正常。

浏览器测试使用模拟时钟与仅在 `--mode test` 启用的确定性状态注入。测试独立使用 5174 端口；开发预览使用 5173 端口。Windows 上 Firefox 和 WebKit 首次运行较慢，因此测试串行执行，每项允许 120 秒，游戏内时间仍由模拟时钟精确控制。

依赖版本锁定于 `package-lock.json`。本机为验证下载的便携运行时和浏览器位于 `.runtime/`，不提交到 Git。生产产物位于 `dist/`。

## Windows 一键启动

- [x] 双击 `开始游戏.cmd` 自动启动隐藏的本机 HTTP 服务并打开默认浏览器。
- [x] 实际执行启动入口成功，`http://127.0.0.1:17863/` 返回 200。
- [x] 连续启动两次，监听端口的进程 ID 保持一致，复用已有服务。
- [x] 服务正确返回页面、JavaScript 资源及 MIME 类型，支持 HEAD 请求。
- [x] 越界文件路径、非法编码、不支持的请求方法和不存在的资源有测试覆盖。

启动器优先使用本机便携 Node.js，缺失时使用 PATH 中的 Node.js。生产页面缺失时自动构建；缺失 npm 依赖时先安装。服务仅绑定 127.0.0.1，启动失败通过 Windows 弹窗提示。
