# 贪吃蛇游戏 MVP 产品设计

## 整体方向

制作一个打开浏览器就能玩的单人贪吃蛇游戏。首版面向使用电脑键盘的玩家，以完整的一局游戏、顺畅的操作和清晰的反馈为核心。

采用固定大小的网格、固定移动速度和简洁界面，让玩家无需学习复杂规则即可开始游戏。

## 核心玩法

玩家控制持续移动的蛇吃食物，每吃一个食物，蛇增长一格并增加 1 分。撞墙或撞到自身时游戏结束；填满棋盘则获胜。

## 主要功能

| 功能 | 设计范围 |
| --- | --- |
| 游戏画面 | 显示固定网格、蛇和食物，三者易于辨认 |
| 移动控制 | 支持方向键和 WASD；禁止直接向当前移动方向的反方向转向 |
| 食物与增长 | 食物随机出现在空格；吃到后蛇增长、分数增加，并生成新食物 |
| 分数展示 | 实时显示本局分数，新一局归零 |
| 开始游戏 | 初始展示开始入口和简短操作提示，玩家主动开始后蛇才移动 |
| 暂停与继续 | 支持暂停按钮和空格键；暂停时蛇停止移动，继续时保留本局进度 |
| 结束与重开 | 显示游戏结束状态和最终分数，可重新开始一局 |
| 胜利反馈 | 填满棋盘时显示胜利和最终分数，支持重新开始 |
| 音效 | 默认开启；吃食物时上升叮咚音、碰撞时低沉爆炸音、有效转向时轻微嘀声；按钮可静音或取消静音 |

## 页面与流程

一个页面完成全部操作：顶部展示游戏名称和分数，中间为棋盘，附近提供操作按钮和键盘提示。

流程：待开始 → 游戏进行中 ↔ 暂停 → 游戏结束或胜利 → 重新开始。

重新开始时恢复初始蛇、方向、食物和分数。游戏结束或胜利后停止移动，等待玩家重开。

## 首版范围

首版提供单人、电脑键盘操作、固定速度和固定棋盘。音效已根据后续需求加入，使用 Web Audio API 实时合成，无需外部音频文件。移动端触控、难度选择、皮肤、排行榜及最高分本地保存留待后续版本。

## 验收与测试要点

- 玩家能够开始、暂停、继续，并在结束后重新开始一局。
- 方向键与 WASD 均可控制蛇，快速连续输入也不能导致直接反向。
- 每吃一个食物增长一格并增加 1 分，食物始终生成在空格。
- 撞墙或撞到自身会结束游戏；移动到本次即将移走的尾部位置不误判为碰撞。
- 暂停期间蛇和分数保持不变，继续后恢复移动。
- 重开后状态完全重置，不继承上一局的分数或暂停状态。
- 填满棋盘后进入胜利状态，不再尝试生成食物。
- 音效默认开启，首次交互后可播放；静音立即停止声音，取消静音恢复后续音效，重开保留静音选择。

实现阶段应围绕上述规则编写自动化测试，并通过浏览器验证完整游戏流程和操作反馈。
